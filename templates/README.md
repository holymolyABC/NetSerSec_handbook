# 재사용 문서 양식

| 양식 | 사용하는 시점 | 저장 위치 |
|---|---|---|
| [운영 절차서](runbook.md) | 같은 작업을 반복할 수 있게 정리 | 해당 기술의 `docs/` 아래 |
| [변경 작업 기록](change-record.md) | 실제 수행한 변경과 검증을 기록 | `docs/cases/YYYY-MM-DD-제목.md` |
| [장애 보고서](incident-report.md) | 장애 분석·복구·재발 방지 기록 | `docs/cases/YYYY-MM-DD-제목.md` |

각 양식을 복사해 작성합니다. 빈 칸은 템플릿에만 두고 완성 문서에서는 `해당 없음` 또는 `확인 필요: 이유`로 정리합니다. 자주 쓰는 절차와 사례를 서로 링크합니다. 템플릿의 미기입 항목은 실제 수행 결과가 아닙니다.
